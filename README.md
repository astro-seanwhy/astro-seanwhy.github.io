# astro-seanwhy.github.io

Personal academic website of Haiyang S. Wang.

The pages are generated by a small Python script that needs only Python 3.11 or newer, with nothing to install.

## Making changes

| To change | Edit |
| --- | --- |
| Publications | `src/data/publications.toml` |
| Talks | `src/data/talks.toml` |
| Research themes: titles, subtitles, figures | `src/data/themes.toml` |
| Which theme a paper belongs to, its one-sentence summary, its figure on the Latest results page | `themes`, `summary` and `figure` in `src/data/publications.toml` |
| Latest-result box on Home and its figure | `src/partials/` |
| Theme and paper figures | `assets/themes/`, `assets/pubs/` |
| Page text | `src/pages/` |
| Contact form connection | `FORMSPREE_ID` in `src/build.py` |
| Search engine ownership codes | `GOOGLE_VERIFICATION`, `BING_VERIFICATION` in `src/build.py` |
| Sidebar and page frame | `src/template.html` |
| Colors and layout | `assets/style.css` |

Then regenerate the pages:

```bash
python3 src/build.py
```

Do not edit the generated `index.html` files directly, because the next build overwrites them.

## Publishing

Every change to `main`, whether pushed from a computer or committed on github.com, is built and published by GitHub Actions (`.github/workflows/pages.yml`). Edits made on github.com therefore go live about a minute later without a local build. The run's progress is under the repository's Actions tab.

## Previewing

```bash
python3 -m http.server 8642
```

Then open http://localhost:8642.
