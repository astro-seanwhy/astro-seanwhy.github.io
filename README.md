# astro-seanwhy.github.io

Personal academic website of Haiyang S. Wang.

The pages are generated by a small Python script that needs only Python 3.11 or newer, with nothing to install.

## Making changes

| To change | Edit |
| --- | --- |
| Publications | `src/data/publications.toml` |
| Talks | `src/data/talks.toml` |
| Page text | `src/pages/` |
| Contact form connection | `FORMSPREE_ID` in `src/build.py` |
| Sidebar and page frame | `src/template.html` |
| Colors and layout | `assets/style.css` |

Then regenerate the pages:

```bash
python3 src/build.py
```

Do not edit the generated `index.html` files directly, because the next build overwrites them.

## Previewing

```bash
python3 -m http.server 8642
```

Then open http://localhost:8642.
